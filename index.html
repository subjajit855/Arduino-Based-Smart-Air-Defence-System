From echo to alert

An educational prototype that shows radar-style detection, direction tracking, alerts and wireless monitoring in one build.

  1. Scan

    The radar servo sweeps the sensor through its arc.

  2. Detect

    HC-SR04 sends a pulse and times the returning echo.

  3. Locate

    Distance is paired with the current angle.

  4. Track

    The rotary servo turns toward the object.

  5. Alert

    Inside the set range, the buzzer sounds.

  6. Report

    HC-05 sends angle, distance and status to a phone or PC.

Two power worlds, one gap

The control electronics and the high-voltage demonstration never share wiring.

Control side

Regulated 5V, common ground.

  • Arduino UNO
  • HC-SR04 and servos
  • HC-05 and buzzer
  • Relay input only
ISOLATION

High-voltage demo

Own supply, switched by the relay.

  • Generator module
  • Separate 9-12V DC supply
  • Enclosed and insulated
  • Never wired to any signal pin

Safety

The high-voltage module is experimental. Keep it physically and electrically isolated from the Arduino electronics.

Enclose and insulate the output, and handle it only with proper precautions. Never use it for ignition, projectile launching or any hazardous function.
